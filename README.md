# 自动演奏器 Lite

原生 WinUI 3 界面 + Python 本地输入引擎，适用于三角洲行动守夜人口琴。

## 下载与安装

在 [Releases](https://github.com/NekoYume517/AutoMusicPlayerLite/releases/latest) 下载 x64 安装包。
支持 Windows 10 2004（19041）及以上、Windows 11。安装包包含 .NET、WinUI、Python 和 VC 运行库，无需自行安装依赖。首次启动为空曲库，使用自己的本地 JSON 或 MIDI 乐谱。

## 功能

- 本地 JSON / MIDI 导入导出；文件夹批量导入；简谱编辑与钢琴试听。
- 自定义分组、收藏、多选批量分组，曲目可属于多个分组。
- 按添加时间、更新时间、曲名升降序排列；中文拼音与首字母搜索、A–Z 索引。
- 乐谱库右侧直接演奏、暂停、试听或重置；演奏控制页面调整节奏与片段。
- 所有页面右上角均可打开置顶演奏小窗：不抢游戏焦点，独立试听、进度、上一首、暂停、下一首；独立选曲搜索面板。
- 演奏与试听共用 0.5–3.0× 连续倍速，保留原始 BPM。
- F6 开始或继续、F8 暂停；失去目标窗口焦点时暂停并释放按键。
- 设置中检查 GitHub Releases 稳定版本，可开启启动时自动检查。下载后验证 SHA-256，确认后关闭播放器并安装，保留本地曲库。

## ZIP 导出与备份

乐谱库点击“多选”，选择曲目后点击“导出 ZIP”；压缩包只含 JSON 谱面，可通过导入重新加入曲库并指定分组。

设置 → 备份与恢复 → 创建备份，保存为 backup-日期.zip，包含全部谱面、分组、收藏、每曲演奏设置和程序设置。恢复备份会先自动保存当前数据到数据目录的 backups 文件夹，再替换曲库和备份内的设置；演奏或试听期间请先停止。

普通身份启动时提供四个选项：保留普通身份、以管理员身份重启、重启并设为默认、不再提醒。设置中可以重新开启提醒或关闭默认管理员启动。管理员重启等待新窗口与引擎就绪后才关闭旧窗口；取消授权或启动失败保留旧窗口。
