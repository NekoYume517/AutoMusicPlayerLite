# 自动演奏器 Lite 2.1.0

1. 安装后打开程序。首次使用时确认提示；初始曲库为空。
2. 在乐谱库点击“导入乐谱”，选取本地 JSON、MID 或 MIDI 文件，可同时选多个。也可在“更多”中批量导入文件夹。
3. 导入前勾选一个或多个分组，可直接新建分组，也可同时收藏。
4. 曲目支持“全部”“默认分组”“收藏”及自建标签。点击加号创建分组；右键自建标签重命名或删除分组。删除分组保留曲目。
5. 点击“多选”，全选或逐首选择，可批量加入分组、移出当前组、收藏或取消收藏。
6. 排序可选添加时间、更新时间、曲名拼音的升序或倒序；曲名排序显示右侧 A–Z/# 索引。搜索支持中文、完整拼音和首字母。
7. 选择曲目后可编辑简谱或导出 JSON / MIDI。MIDI 导出保留原始 BPM；本地时间轴导入近似为累计 1/8 拍，原生自定义时值保持。
8. 在演奏控制中调整片段、BPM、移调和真人化节奏。倍速范围 0.5–3，演奏与试听共用，小窗中也能调节。
9. F6 开始或继续，F8 暂停。开始后 3 秒内切回游戏。目标窗口焦点变化时会暂停并释放按键。
10. 演奏小窗置顶且鼠标操作不激活窗口，有进度、上一曲、播放或暂停、下一曲。单独选曲面板提供搜索与选择。

## 软件更新

设置 → 软件更新中可手动检查 GitHub Releases 稳定版本。开启启动自动检查后，每 24 小时最多检查一次。新版显示版本说明，点击“下载并安装”后确认，下载并校验 SHA-256，再关闭播放器启动安装。网络错误可重试，校验失败不会启动安装。发布页可直接查看所有版本。

公开版数据目录：`%LOCALAPPDATA%\AutoMusicPlayerLitePublic`。升级和卸载保留曲库、分组、收藏。与其他发行版使用独立数据目录，可手动导入旧数据库。

游戏以管理员身份运行时，可在设置中选择“以管理员身份重新打开”。文件选择器支持管理员权限。

MIDI Type 0/1 支持速度变化、延音、休止、和弦及半音；Type 2 和 SMPTE 请先转换。程序仅针对三角洲行动口琴。
